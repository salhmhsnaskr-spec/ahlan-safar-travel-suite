- التراجع: تعديلات وظائف فقط دون إزالة أعمدة أو بيانات؛ الحفاظ على تاريخ التعريفات بالمigrations والإصلاح الأمامي. لا تعاد صلاحيات خطرة افتراضيًا. الاستعادة اليومية تعيد البيانات والمخطط وتفقد ما بعدها وتوقف القاعدة دقائق ولا تشمل Storage.

## سجل الجولة السابقة (3 نوفمبر؛ ليس وصفًا للحالة الحالية)

## الحكم
الطلب غير مكتمل، ولا تكفي الاختبارات المحلية لإعلان جاهزية التشغيل التجاري أو الحذف الشامل.

## نُفّذ في الكود هذه الجولة
- مطابقة آخر منفذ بالكيان ومعرّف السجل مع استبعاد أحداث المكاتب الأخرى والأحداث الفاشلة.
- أعمدة منفصلة لحقول الخدمات في تقارير الطلبات من تعريف النموذج الديناميكي؛ تجاهل القيم المخفية غير ذات الصلة.
- بحث المدينة في لوحة المالك دون حساسية حالة الأحرف؛ التصدير كان يستخدم القائمة المفلترة بالفعل، ولم يُعد بناؤه.
- أسماء أوراق Excel صالحة وفريدة بعد الاقتطاع، بما يشمل تعارض اسم الملخص.
- التحقق من غياب الملف يرفض أخطاء 400 العامة والنتائج غير الصريحة؛ لا تُعلن نتيجة نجاح عند فشل حفظ نتيجة الحذف.
- ضبط عرض جداول الطباعة والتفاف الكلمات لمنع خروجها عن الصفحة.

## قاعدة البيانات
فحص قراءة فقط للسياسات الحالية؛ لم تُطبّق تغييرات جديدة ولم تُكتب بيانات أو تُحذف سجلات.
الدوال الحالية المتاحة تؤكد وجود أذونات السجلات وهوية المكتب ودوال لوحة المالك وطابور حذف العملاء والوثائق، لكنها لا تثبت اكتمال التصميم المطلوب:
- begin_customer_deletion وbegin_document_deletion يحذفان بيانات الوثائق قبل تأكيد إزالة الملفات. المسارات تبقى في jobs، لكن ذلك ليس تصميم Storage-first الكامل.
- عامل الحذف الدائم وحذف المكتب محجوبان محليًا؛ وظائفهما وأعمدة التأجير والجدولة ليست ضمن المخطط المشترك الحالي.
- work_owner يعتمد created_by عند غياب الإسناد، خلاف قاعدة الإسناد فقط؛ work_allowed لا يثبت مكتب السجل قبل استثناء المدير.
- team_performance يُعيّن _admin=true؛ يحتاج مواءمة صريحة بين قراءة أعمال المكتب وتقارير أداء الموظفين الخاصة قبل تغيير الصلاحيات.

## الاختبارات
نجح 32 اختبارًا مركّزًا في خمسة ملفات: التقارير والتصدير وحقول الخدمات وغياب ملفات Storage وحفظ نتيجة الحذف. هذه محاكاة محلية وليست اختبارًا للتخزين الحقيقي أو جلسات متعددة أو التزامن.
فُتح /demo/reports مع منع الاتصالات الخارجية، واختير تبويب التصدير وتاريخ البداية؛ نُزّل Excel بأوراق الملخص والعملاء والطلبات والحجوزات، وفُحص اتجاه RTL في الملف. فُتحت صفحة الطباعة وأُنتج PDF محليًا. لا أخطاء JavaScript في هذا التدفق.
آخر سجل التحقق الآلي أظهر build OK؛ لم يُشغّل بناء يدوي.

## المتبقي وشروط تنفيذه
1. دليل أحدث نسخة احتياطية UTC غير متوفر: المستخدم تجاوز سؤال التوقيت، فلا يجوز افتراض وجود نسخة قابلة للاستعادة.
2. قبل تغيير مؤثر: تصدير الحالة الحالية عبر More → Database → Manage → Settings → Export project data، وتنزيل الملفات من More → Storage. النسخ اليومية والتصدير لا يشملان ملفات التخزين.
3. الاستعادة اليومية تعيد بيانات ومخطط المشروع نفسه، وتفقد التغييرات اللاحقة وتوقف القاعدة دقائق؛ لا استعادة لحظة معينة أو جدول منفرد ولا ضمان عكس آمن.
4. خطة التراجع المطلوبة: تعديلات إضافية دون إسقاط أعمدة، حفظ تعريفات الدوال والسياسات السابقة، وإصلاح أمامي عند الفشل؛ لا إعادة منح صلاحيات خطرة كخطة افتراضية. استعادة القاعدة وحدها لا تعيد الملفات المحذوفة.
5. بعد تحقق الاستعادة: تصميم Storage-first محفوظ الصفوف، أقفال العميل لا المكتب، وظائف إنهاء مؤمّنة وتأجير ومعالجة إعادة المحاولة قبل تفعيل الحذف؛ اختبارات على سجلات منشأة للاختبار فقط وليس العملاء الحقيقيين.
6. قبول فعلي للجلسات والأدوار وStorage والتزامن ورفع الشعار، وتسليم بريد الدعوات ونطاق الإرسال، ما زال غير مثبت. لا حسابات تجريبية مؤكدة استُخدمت هذه الجولة.

لم يُنشأ مشروع أو خدمة، ولم يُنشر الموقع.
