# تقرير المرحلة الأولى — أهلاً سفر

## الحكم

**استخراج بنية التطبيق وإعادة بنائها بنيويًا نجحا؛ المرحلة ليست مكتملة بالكامل.** لم يتوفر تشغيل مستقل حقيقي لمنصة قاعدة البيانات والمصادقة والتخزين، لذلك لا يوجد إثبات لإعادة بناء المنصة كاملة من الصفر. لم يبدأ الاختبار التكاملي.

## كيف تحققنا؟

1. استعلامات قراءة فقط لكتالوج PostgreSQL الحالي؛ لا قراءة لصفوف العملاء أو المستخدمين. قراءة إعداد الحاوية فقط: خاصة، وحد الملف 20 MiB.
2. إنشاء ستة ملفات مرتبة تستوعب الحالة النهائية الحالية؛ لا إعادة تشغيل لسلسلة التغييرات التاريخية بعد هذا الأساس.
3. بناء قاعدة PGlite جديدة في الذاكرة، بإضافتي pgcrypto وuuid-ossp الحقيقيتين وهياكل اعتماد فارغة.
4. تطبيق الملفات الستة كاملة، ثم مقارنة كتالوج النسخة الجديدة مع التعريفات المستخرجة، والتحقق من أن كل جداول التطبيق خالية من البيانات.
5. معالجة اختلاف تمثيل NOT NULL في إصدار محرك التحقق، وحفظ دقة حدود bigint أثناء المقارنة؛ الفحص النهائي نجح. كانت هناك محاولات تصحيح لأداة المقارنة فقط، لا اختبارات عمليات ولا إعادة للاختبارات الـ92.
6. إغلاق القاعدة المؤقتة؛ لا حسابات أو جلسات أو بيانات اختبار تطبيقية أنشئت.

## ما تعذر إثباته أو لم يُنسخ؟

- **إعادة بناء المنصة المحلية الكاملة غير متحققة:** Docker وPodman غير متاحين. إعداد المشروع المحلي مكتوب، لكنه لم يُختبر بتشغيل أو إعادة ضبط منصة فعلية.
- مخططات المنصة المدارة `auth` و`storage` و`realtime` و`vault` وتواريخها وصلاحياتها الداخلية لا تُعاد كتابتها من الإنتاج؛ توفرها المنصة المستقلة عند تشغيلها. استخرجت توقيعات تبعيات التطبيق وسياسات التخزين فقط. لم يثبت تطابق نسخة المنصة المحلية مع الحالية.
- لا نسخ للأدوار القابلة لتسجيل الدخول أو عضوياتها أو كلمات مرورها؛ الدور المحلي `sandbox_exec` بلا تسجيل دخول لحفظ شكل الصلاحيات فقط.
- إضافات المراقبة وvault حُصرت كأسماء وإصدارات، ولم تُقرأ محتوياتها أو يُعاد تركيبها منفردة؛ ليست تبعيات دوال التطبيق الحالية.
- لا توجد views أو قواعد إضافية أو محفزات أحداث أو إحصاءات ممتدة تطبيقية أو عضوية نشر للجداول العامة حسب الحصر.
- لا تنفيذ لمسارات الدوال أو جلسات حقيقية أو تزامن أو قبول دعوات؛ تركيب تعريف الدالة ليس إثباتًا لمسارات تشغيلها.
- لا بيانات كتالوج الخدمات أو مالك المنصة أو أي صفوف عملاء/مستخدمين، عمدًا وفق شرط استخراج البنية فقط.

## السلامة والخطوة التالية

لم تُرسل أي عمليات كتابة أو تغييرات إعداد إلى البيئة الحالية، ولم تستخدم حسابات الإنتاج أو أسرارها. لم تُنشأ خدمة أو موارد مدفوعة، ولم تُضف GitHub Actions، ولم يُعد الفحص الأمني أو الاختبارات الـ92، ولم يحدث نشر.

دليل عدم التغيير هو أن جميع العمليات على البيئة الحالية كانت SELECT فقط، وليس مقارنة شاملة لبيانات الإنتاج أو نفي تغييرات أطراف أخرى.

**متوقف للمراجعة.** لإغلاق المرحلة يلزم لاحقًا تشغيل إعادة بناء بنيوي فقط على منصة مستقلة فعلية بإذن المستخدم؛ لا حاجة لأسرار الإنتاج. لا أوصي باعتبار هذا تقرير قبول تكاملي أو شهادة جاهزية للنشر.
